# The Soucy Family Website — Design v2

Static GitHub Pages website for https://thesoucys.net.

## Deploy
Upload `index.html`, `assets/site.css`, `recipes/index.html`, and `recipes/cajun-rotisserie-chicken-pasta/index.html` to the matching paths in the `mike97722/thesoucys.net` repository. Keep the existing `CNAME` file and GitHub Pages custom-domain settings.

## Recipe import compatibility
The Cajun pasta recipe retains the original Schema.org Recipe JSON-LD and HTML microdata markup, ingredient strings, instruction text, times and yield from the version validated with AnyList. Only site layout and styling have changed. Test AnyList again after publishing.

## Future updates
Edit `assets/site.css` to change shared styling across all pages.
