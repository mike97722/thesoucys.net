# The Soucy Family

Static GitHub Pages website for thesoucys.net.

- `/` — family homepage
- `/recipes/` — recipe library
- `/recipes/cajun-rotisserie-chicken-pasta/` — tested AnyList-compatible recipe

Keep the `CNAME` file if GitHub Pages created one, and preserve the custom domain setting in Settings → Pages. Recipe pages contain Schema.org Microdata and JSON-LD.
